\begin{exercise}{Integration af trigonometriske funktioner 1-1}

Bestem det ubestemte integral $\int \sin(x) \, dx$.

\answerbox{-\cos(x) + C}

\hint

Integralet af sin(x) er -cos(x) plus en konstant.

\hint

Regel: $\int \sin(x) \, dx = -\cos(x) + C$

\end{exercise}

\begin{exercise}{Integration af trigonometriske funktioner 1-4}

Bestem det ubestemte integral $\int (\sin(x) + \cos(x)) \, dx$.

\answerbox{-\cos(x) + \sin(x) + C}

\hint

Integrer hvert led separat:

\hint
\[
\int \sin(x) \, dx + \int \cos(x) \, dx = -\cos(x) + \sin(x) + C
\]

\end{exercise}

\begin{exercise}{Integration af trigonometriske funktioner 1-5}

Bestem det ubestemte integral $\int 3\sin(x) \, dx$.

\answerbox{-3\cos(x) + C}

\hint

Konstanten kan trækkes udenfor integralet:

\hint
\[
\int 3\sin(x) \, dx = 3 \int \sin(x) \, dx = 3(-\cos(x)) + C = -3\cos(x) + C
\]

\end{exercise}
