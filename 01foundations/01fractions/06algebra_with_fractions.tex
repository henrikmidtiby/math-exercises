\begin{exercise}{Brøker med variabler 1-1}

Forenkle udtrykket $\frac{2x + 4}{2}$.

\answerbox{x + 2}

\hint

Opdel brøken i to separate brøker.

\hint
\[
\frac{2x + 4}{2} = \frac{2x}{2} + \frac{4}{2}
\]

\hint

Reducer hver brøk.

\hint
\[
\frac{2x}{2} + \frac{4}{2} = x + 2
\]

\end{exercise}
