\begin{exercise}{Addition af brøker med fælles nævner 1-1}

Bestem $\frac{2}{7} + \frac{3}{7}$.

\answerbox{\frac{5}{7}}

\hint

Når brøkerne har den samme nævner, kan du lægge tællerne sammen.

\hint

Begrundelse: $\frac{a}{c} + \frac{b}{c} = \frac{a + b}{c}$

\hint

Anvend reglen på opgaven
\\[\frac{2}{7} + \frac{3}{7} = \frac{2 + 3}{7}\]

\hint

Udregn summen i tælleren
\\[\frac{2 + 3}{7} = \frac{5}{7}\]

\end{exercise}
